The Actual Value

The limit tells us what height we expect the car to be at based on its surrounding path. But the exact moment you hit $x = 5$, ZAP!

$$f(5) = 1\text{ meter}$$

The Calculus Takeaway

The limit looks at the journey, while the actual value looks at the destination. Because the journey of the car from both sides of $x = 5$ meters expected the ground, the limit is $0$. But because of the portal, the actual value is $1$.

More generally, we can say that a limit is the value that a function approaches as the input gets closer and closer to a specific point.

General Limit Notation

In general, we write the limit of a function as the input approaches a value $a$ like this:

$$\lim_{x \to a} f(x) = L$$

This means: as $x$ gets closer and closer to $a$, the function $f(x)$ gets closer and closer to $L$.

Let's go back to our car example, where $f(x)$ represents the car's height.

What is $\lim_{x \to 4.999} f(x)$ equal to?

Continuing with our car example, where \(f(x) = 0\) for all \(x \neq 5\) and $f(5) = 1$.

Suppose $\lim_{x \to a} f(x) = 0$. Which values of $a$ could make this statement true? Select all that apply.






For our car example, the function is $0$ for every $x$ except the one instant at $x=5$, so we know that:

$$\lim_{x \to a}f(x)=0 \quad \text{for all} \quad x\neq 5$$

For $a=5$, we know that $f(5)=1$, but the limit only cares about values of $f(x)$ when $x$ gets arbitrarily close to $5$, not the value exactly at $5$. Since all nearby values on either side are 0, the function approaches 0 as $x \to 5$.

$$\lim_{x \to 5} f(x)=0$$

The graph at $x=5$ looks like it has a "hole" at $(5,0)$, where the actual function value is suddenly lifted to $(5,1)$. Holes are also known as removable discontinuities.

$$\lim_{x \to a} f(x) = L\quad \neq \quad f(a)$$

In general, a removable discontinuity occurs when the limit exists but is not equal to the function value at that point. The road has a perfectly predictable trend, but a single point has been "removed" and popped up into the air!

This illustrates a key concept: a function's limit at a point can exist even if the function's value at that exact point is different or undefined.

What comes next?

The hole in the road was our first clue that a function can have a perfectly good limit while still behaving strangely at one exact point. That gap between nearby behavior and actual value is exactly where continuity begins.
